# 🎯 Vuscan

Веб-приложение для анализа и мониторинга безопасности веб-приложений через сканирование уязвимостей.

## 📝 Описание проекта

Приложение помогает разработчикам и security-специалистам автоматически обнаруживать уязвимости в веб-приложениях. Пользователь указывает целевой домен, система проводит комплексное сканирование и предоставляет детальный отчет о найденных угрозах и рекомендации по их устранению.

## 🛠 Технологический стек

### 🎨 Frontend
- ⚛️ React + TypeScript - UI
- 🔄 MobX - state manager
- 🌐 Axios - HTTP-запросы к API
- 🔌 TanStack Query - кэширование запросов 
- 🎨 CSS Modules - стилизация
- 📏 ESLint + 💅 Prettier - линтинг и форматирование кода

### 🚀 Backend
- 🖥 Express.js + 🔷 TypeScript - серверная часть
- 🗄 MySQL - база данных
- 📃nodeMailer - рассылка по почтам
